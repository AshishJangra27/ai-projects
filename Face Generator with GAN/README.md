# Face Generation with GAN

[![Open In Kaggle](https://kaggle.com/static/images/open-in-kaggle.svg)](https://www.kaggle.com/code/ashishjangra27/face-generation-with-gan)  
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1qmqKQGatkZ9UA7HV1RCE-EmeC5bBGwwc?usp=sharing)

This project demonstrates **face generation using Generative Adversarial Networks (GANs)**.  
It trains a GAN to generate realistic human faces from random noise vectors.

---

## Workflow
1. Data Preparation – Load and preprocess face dataset.  
2. Model Architecture – Define the Generator and Discriminator using TensorFlow/Keras.  
3. Training – Train GAN by alternating between generator and discriminator updates.  
4. Evaluation – Monitor training progress with generated images.  
5. Inference – Generate new faces from random noise inputs.  

---

## Tech Stack
- Python  
- TensorFlow / Keras  
- NumPy  
- Matplotlib  
- tqdm (progress visualization)
