# Object Detection with YOLO

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1G5P4Szuz0corBdSpYFPhPAAMgJyupnBs?usp=sharing)

This project demonstrates **object detection** using the **YOLO (You Only Look Once)** framework.  
It includes experiments with Haar Cascades and modern YOLOv8 to detect objects in images.  

---

## Workflow
1. **Setup** – Install dependencies (Ultralytics, OpenCV, etc.).  
2. **Haar Cascades** – Explore classical object detection with Haar features.  
3. **YOLOv8 Predictions** – Run detection on sample images using pretrained YOLOv8 models.  
4. **Visualization** – Display predictions with bounding boxes.  
5. **Analysis** – Compare results from Haar Cascades vs YOLO.  

---

## Tech Stack
- Python  
- OpenCV  
- Ultralytics YOLOv8  
- NumPy, Pandas  
- Matplotlib
